# Application

Personal meal planner & recipe manager

# Getting started

npm install
cp .env.example .env
npm run dev

# Environment variables

PORT: Set the server port. Default is 4000
USDA_API_KEY: Required for external food search endpoint

# Testing

http://localhost:4000/api/recipe/recipe1 — returns a sample recipe.
http://localhost:4000/api/foods/search?q=chicken — searches for food using the external API and requires a configured API key.
